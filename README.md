# College Election System

An online college election management system developed using PHP, MySQL, JavaScript, HTML and CSS with face verification and role-based authentication.

## Features

- Secure student login system
- Face verification for voting
- Admin dashboard
- Presiding officer dashboard
- Student dashboard
- Election management
- Candidate management
- Real-time voting system
- Vote history tracking
- Responsive user interface

## User Roles

### Admin
- Manage students
- Manage elections
- Manage presiding officers
- View election results

### Presiding Officer
- Monitor elections
- Approve candidates
- Manage election activities

### Student
- View active elections
- Cast votes securely
- View voting history
- Face verification before voting

## Technologies Used

- PHP
- MySQL
- JavaScript
- HTML5
- CSS3
- Face API.js
